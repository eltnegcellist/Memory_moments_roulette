## 発見した不具合: GIF動画名検索が一致しない（Medium）

対象: S02、Desktop Chromiumで4/4回、モバイル相当Chromiumで1/1回再現。main `23d15e8`。合成動画A/BをGIF画面の入力から取り込む。保存された `deckSources.fileName` が `synthetic-a.webm` と `synthetic-b.webm` であることを確認。「別の動画を選ぶ」から検索欄へ `synthetic-a` を入力すると、期待するAのカードが表示されず、検索該当なしになる。画面は「日付・動画名で検索」と案内している。自動再現: `npx playwright test --project=desktop-chromium tests/e2e/gif.spec.ts --grep 'S02/S19'`。失敗時のtraceとスクリーンショットが生成される。

原因候補: `deck.js` のGIF用カタログ `__memoryGifListSources` は日付ラベルを渡すが `fileName` を渡さず、`features.js` の `renderGifSourceCards` はその日付ラベル等のみを検索する。通常ライブラリの `sourceSearchText` はファイル名を含む。最小修正案: GIFカタログに検索用ファイル名を含め、GIFのフィルターでも検索対象にする。旧履歴は従来のタイトルを維持し、日付検索・大小文字・選択状態を回帰確認する。アプリ本体は未修正。

初期テストで停止コマを1と誤認した失敗は、明示選択後に3回成功し、アプリ不具合として数えない。初回のDB件数差も非同期初期化前後を比較していたテストの問題であり、初期化待ち後の再実行では不変。

CI初回は15件中14件成功、1件失敗。自動回転中のコマを固定と仮定したテスト側の競合を修正し、コミットc3a617bのPRスモークCIは成功（当時S02は対象外）。S02をスモークに追加し、追加変更のCIは未確認。追加変更に対するCIは未確認。PWAのキャッシュ更新、Galaxy S25、Android共有シート、LINE互換性は未検証。未テストの大部分があるため、重大不具合がないとは結論できない。

再現: `npm ci`、`npx playwright install chromium`、`npx playwright test --project=desktop-chromium tests/e2e/receive.spec.ts tests/e2e/gif.spec.ts`。探索は `npx playwright test --project=desktop-chromium tests/e2e/explore.spec.ts`。
