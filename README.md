# 思い出ルーレットおみくじ

**自分では選ばなかった一枚に、偶然出会う。**

写真を撮るとき、私たちは笑顔やきれいに写った「いい瞬間」を残そうとします。  
でも動画には、その間の半目や動きの途中、思いがけない表情まで、たくさんの一瞬が残っています。

普通なら写真にしなかった一瞬を、ルーレットで偶然引く。  
「こんな顔してたんだ」「こんな一瞬あったんだ」と、家族や身近な人と楽しむ。  
そして、その偶然の一枚におみくじを重ねて、今日だけの結果として楽しむ。

**よく撮れた一枚を探すのではなく、自分では選ばなかった一枚に出会う。**

それが、このアプリの中心にある体験です。

## v1.1 — 思い出おみくじデッキ

v1.1では、1本の動画ごとに遊ぶだけでなく、**複数の思い出動画から抽出した一瞬を端末内にためて、いつでも引ける「思い出おみくじデッキ」**を追加しました。

### 基本の流れ

1. 「思い出動画を追加する」から、1本または複数の動画を選ぶ
2. 各動画から8〜15個程度の一瞬を自動抽出
3. 抽出した一瞬を端末内のデッキに保存
4. 保存済み動画をサムネイル一覧から選ぶ
5. 選んだ動画だけで「おみくじを引く」
6. 新しい動画を撮ったら、あとからデッキへ追加

長い動画だけが候補を占有しないよう、1本あたりの抽出数には上限を設けています。

### 同じ結果を繰り返しにくい抽選

デッキでは**シャッフルバッグ方式**を採用しています。

原則として、デッキ内の候補を一巡するまでは同じ一瞬を結果として再び出しません。一巡すると再シャッフルします。

### 運勢と写真は別々

v1.1では、写真の特徴と運勢を切り離しました。

笑顔だから大吉、半目だから凶、といった判定はしません。  
止まった一瞬とは独立して、その場で運勢を抽選します。

**写真の出来を運勢で評価するものではありません。**

## このアプリが目指すこと

### 自分では選ばなかった一枚に出会う

写真では、笑顔やきれいに写った姿など、「残したい瞬間」を自分で選びます。  
一方、動画には、その前後や途中の一瞬まで残っています。

- 半目になった顔
- 動きの途中
- ちょっと変なポーズ
- 思いがけない表情
- 本人も気づいていなかったような一面

このアプリは、それらを「失敗写真」として扱うのではありません。  
また、変な写真や笑える写真を高く評価するものでもありません。

**普通なら自分では選ばなかった一瞬に、偶然出会うことそのものを楽しみます。**

そこで生まれる「こんな顔してたんだ」「こんな一瞬あったんだ」という発見を、家族や身近な人との会話や笑いにつなげることを目指しています。

### おみくじは、偶然をもう一段楽しむための仕掛け

まず、どの動画のどの一瞬で止まるか分からない。  
さらに、止まった一枚とは独立して、その場で運勢も決まる。

**自分では選ばなかった一枚との偶然の出会いに、もう一つの偶然を重ねる。**

それが「思い出ルーレットおみくじ」です。

### もともとは育児動画から始まりました

赤ちゃんの動画をコマ送りすると、写真としては残していなかったさまざまな表情が見つかることから始まったアイデアです。

現在は、赤ちゃんや子どもの成長記録だけでなく、家族、友人、ペット、旅行、結婚式、イベントなど、さまざまな思い出動画で使える形に広げています。

---

## 動画から一瞬をどう選ぶ？

候補抽出では、

- 何も判別できないほど破綻したフレームを避ける
- 真っ黒・真っ白に近いフレームを避ける
- ほぼ同一のコマが大量に並ぶのを減らす
- 動画内の一部分だけに偏りすぎないようにする
- 見た目の違う一瞬を幅広く残す

といった処理を行います。

一方で、

- 半目
- 変顔
- 動きの途中
- 少しのブレ
- 横向き
- 何気ない場面

だからという理由では除外しません。

### 特徴度

LAB設定では「特徴度」を表示できます。

これは写真の品質点ではありません。  
「くっきり」「珍しさ」「前後からの変化」などを、候補同士の違いを見るための補助情報として表示するものです。

運勢の決定には使用しません。

## デッキ管理

保存済み動画は、ファイル名だけの一覧ではなく**動画サムネイルのライブラリ**として表示します。

- ブラウザから取得できる動画ファイルの日付をもとに月ごとにグループ表示
- サムネイルをタップして今回使う動画を複数選択
- 動画名検索
- 新しい順 / 古い順
- 「すべて選択」「選択解除」
- 選択状態を端末内に保存
- 追加済み動画の本数
- 保存している一瞬の数
- 使用容量
- 動画単位の削除
- デッキ全体の削除
- バックアップ
- 復元

新しく追加した動画には長辺320px程度の小さな専用サムネイルを保存します。既存のv1.1デッキについても、最初の候補画像からサムネイルを自動生成するため、元動画を選び直す必要はありません。大量デッキでは画面に近いサムネイルだけを遅延生成・読み込みし、おみくじ開始時も選択した元動画の候補だけをIndexedDBから読み込みます。

写真を1枚ずつ整理する写真管理アプリにはせず、**スマートフォンの写真アプリに近い見た目で、元動画単位を選ぶ**ためのライブラリにしています。

### 重複動画

ファイル名、ファイルサイズ、更新日時、動画時間から動画を識別し、同じ動画の二重追加をできるだけ防ぎます。

---

## 保存容量

候補画像は元動画そのものではなく、ルーレット用の静止画として保存します。選抜後の一瞬だけを長辺最大1280pxで再取得し、対応ブラウザではWebP、非対応時はJPEGで保存します。

現在の目安：

- 1動画：8〜15個
- 通常の保存画像：長辺最大1280px
- 奇跡リプレイ：長辺420px・12コマ・WebP品質0.70（非対応時JPEG）
- 通常候補：停止位置の約3秒前 → 停止位置
- 冒頭2.5秒未満：停止位置 → 約3秒後を保存し、逆向きに再生
- 最大：1,500個の一瞬
- アプリ側のデッキ上限：約650MB
- 実際にはブラウザの利用可能容量が少ない場合、そちらを優先して保存を停止

利用可能な環境ではブラウザのストレージ使用量も確認します。

---

## 保存の耐久性とバックアップ

デッキはIndexedDBに保存します。

利用可能な環境では `navigator.storage.persist()` を使って永続保存を要求しますが、ブラウザデータは端末・ブラウザの操作や保存領域の状況によって消える可能性があります。

そのため、

- 継続利用する場合はホーム画面へ追加
- 大切なデッキは「デッキを書き出す」でバックアップ

を推奨します。

バックアップには候補画像とメタデータを含め、**元動画そのものは含めません。**

---

## 複数動画の処理

複数動画を選んだ場合は1本ずつ処理し、1本終わるごとにデッキへ保存します。

処理中にタブをバックグラウンドへ移した場合は処理を一時停止し、同じページが残っていれば戻ったときに続きから再開します。

ブラウザ自体がページを終了した場合、完了済みの動画は残りますが、未処理の動画は再選択が必要です。

## 主な機能

### 🎴 おみくじモード

思い出デッキまたは従来の保存ルーレットから一瞬を引き、STOP時に運勢を独立抽選します。

### 🎯 通常ルーレット

運勢を付けず、どの一瞬で止まるかだけを楽しめます。

### ✨ 奇跡の一枚 / 🌈 大逆転大吉

低い確率で特別演出が発生します。

「奇跡の一枚」は最高品質の写真という意味ではなく、その場で偶然出会った特別な一瞬という位置付けです。

元動画を利用できる場合は従来どおり元動画からスローリプレイします。デッキへ保存した候補には、長辺420px・12コマの低解像度リプレイを別領域に保存するため、後日元動画を選び直さなくてもスローリプレイできます。通常は停止位置より前の約3秒、動画冒頭の候補だけは停止位置より後ろの約3秒を保存して逆向きに再生します。

### 🖼 今日の一枚

結果の中から「残しておきたい」と思った一瞬をアプリ内に保存できます。

### 🎞 履歴GIF

GIFは**同じ元動画から引いた一瞬だけ**を使い、元動画内の時刻順に並べます。デッキ内で複数の動画から結果が出ていても、異なる動画のコマを1本のGIFに混ぜません。複数の元動画に2枚以上の履歴がある場合は、GIFにする元動画を選べます。

## プライバシー

個人的な思い出動画を扱うため、**動画や写真を解析用サーバーへ送らないこと**を重要な設計条件にしています。

動画のフレーム抽出、候補比較、デッキ保存、運勢抽選、GIF生成、「今日の一枚」の保存などはブラウザ内で行います。

元動画を解析用サーバーへアップロードするAPIはありません。

---

## 既存v1.0データ

v1.0までに保存したルーレットや「今日の一枚」は削除せず、そのまま残します。

v1.1の思い出デッキは新しい保存領域を追加して実装しています。

## 設定

ホームの「設定」に、ルーレット作成に関する設定とデータ管理をまとめています。

### ルーレット設定

- **抽出枚数**：おまかせ（8〜15枚） / 8枚 / 12枚 / 15枚
- **通常ルーレットにする**：運勢なしで「どの一瞬に止まるか」だけを楽しむ
- **運勢サンプルを表示する**：候補確認用の運勢サンプルを表示

これらは新しい動画から作る場合も、過去の動画から作る場合も共通です。設定値は端末内に保存され、次回以降にも引き継がれます。

作成画面には設定項目を置かず、動画選択と処理状況だけに集中できる構成にしています。

---

## LAB設定

画面右上のバージョン表示を5回タップすると、実験・確認用設定を表示できます。

LABでは、特徴度表示、豪華演出、特別演出の強制表示、アプリデータの完全初期化などを確認できます。
