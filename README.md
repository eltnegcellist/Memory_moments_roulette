# 思い出ルーレットおみくじ

**動画の中から、思いがけない一瞬に出会うWebアプリ。**

**公開版：v1.3.0**（12言語対応、共有・受信機能を含む）

**Webアプリ：[思い出ルーレットを開く](https://memory-moments-roulette.pages.dev/)**

## できること

- 動画から候補フレームを抽出し、ルーレットやおみくじを楽しむ
- 保存済みの動画をデッキから選ぶ
- お気に入り・ルーレット履歴を確認する
- 動画からGIFを作成する
- 写真・動画・相手も遊べるルーレット形式で共有する
- ひみつスタンプを使って、共有する画像の一部を手動で隠す
- デッキのバックアップと復元を行う

## 利用環境

スマートフォン向けのWebアプリです。対応ブラウザではホーム画面に追加して利用できます。ファイルの保存先や動画形式はブラウザ・端末によって異なります。

## データとプライバシー

動画のフレーム抽出やデッキの保存など、基本的な処理はブラウザ内で行います。動画や写真を解析のためにアプリ専用サーバーへ自動送信する仕組みはありません。

共有操作では、利用者が選択した外部サービスの取り扱いが適用されます。ひみつスタンプで顔を隠しても、背景などから人物が識別される場合があります。共有前に全コマをご確認ください。

デッキや履歴はブラウザの保存領域を使用します。ブラウザデータの削除などで失われることがあるため、大切なデータはバックアップしてください。
